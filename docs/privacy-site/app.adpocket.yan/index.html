Политика конфиденциальности

Последнее обновление: 21 сентября 2026 г.

Коротко. AdPocket — независимое приложение для просмотра статистики Рекламной сети Яндекса (РСЯ). Оно не имеет собственного сервера. Ваш OAuth‑токен и все данные статистики хранятся только на вашем устройстве и передаются только в API Яндекса. Приложение не содержит рекламы, аналитики и трекеров и не передаёт данные разработчику или третьим лицам.

AdPocket не является официальным приложением Яндекса. Яндекс, Рекламная сеть Яндекса и связанные товарные знаки принадлежат ООО «Яндекс».

1. Кто обрабатывает данные

Разработчик приложения (далее «мы») — физическое лицо, контакт указан в разделе 10. Приложение работает полностью на устройстве пользователя; мы не получаем доступ к вашим данным, не видим их и не храним.

2. Какие данные использует приложение и где они хранятся

ДанныеЗачемГде хранятся
OAuth‑токен API статистики РСЯ (один на каждый добавленный аккаунт)Запросы статистики к API Яндекса от вашего имениТолько на устройстве: Android Keystore / iOS Keychain (защищённое хранилище системы). На iOS токен доступен также виджету приложения через общую группу Keychain.

Приложение не собирает и не хранит: имя, e‑mail, номер телефона, геолокацию, контакты, идентификаторы рекламы, данные об использовании, отчёты об ошибках. У приложения нет учётных записей на нашей стороне.

3. Кому передаются данные

Единственный получатель сетевых запросов — серверы Яндекса: partner2.yandex.ru и partner.yandex.ru (API Рекламной сети Яндекса). В каждом запросе передаётся ваш OAuth‑токен в заголовке Authorization, а также параметры отчёта (период, показатели, фильтры, язык, валюта). Обработка данных Яндексом регулируется его документами: Пользовательское соглашение API Партнёрского интерфейса и Политика конфиденциальности Яндекса.

Мы не передаём данные никому другому. В приложении нет SDK аналитики, рекламных SDK, сервисов сбора ошибок и push‑серверов.

4. Разрешения и функции устройства

  • Интернет — запросы к API Яндекса.
  • Биометрия / код устройства (Android USE_BIOMETRIC, iOS Face ID / Touch ID) — только если вы включите «Блокировку приложения». Биометрические данные обрабатываются операционной системой и не передаются приложению.
  • Виджет главного экрана — показывает кэшированную статистику; на Android при включённом «Фоновом обновлении» приложение примерно каждые 30 минут запрашивает статистику у API Яндекса; на iOS виджет обновляет данные сам по расписанию системы.
  • Оптимизация батареи (Android) — по вашему согласию приложение открывает системный список оптимизации батареи, чтобы вы могли исключить AdPocket и фоновое обновление виджета не останавливалось. Специальных разрешений для этого не запрашивается.
  • Уведомления — локальные, формируются на устройстве по вашему расписанию; серверы push‑уведомлений не используются.

5. Сроки хранения и удаление

Данные хранятся на устройстве, пока вы пользуетесь приложением. Удалить аккаунт и его токен можно в «Настройки → Аккаунты → Удалить аккаунт»; кэш отчётов — «Очистить кэш отчётов». Удаление приложения удаляет все его данные. Отозвать токен на стороне Яндекса можно в интерфейсе partner.yandex.ru.

6. Безопасность

Токены хранятся в защищённом хранилище операционной системы, все запросы идут по HTTPS. Мы рекомендуем включить «Блокировку приложения», если устройством пользуется кто‑то ещё. Мы не можем восстановить токен или данные — у нас их нет.

7. Дети

Приложение предназначено для партнёров Рекламной сети Яндекса и не адресовано лицам младше 18 лет.

8. Ваши права

Поскольку данные находятся только на вашем устройстве, вы полностью контролируете их: просмотр, изменение и удаление доступны в приложении. Если у вас есть вопросы о данных, обрабатываемых Яндексом, обратитесь в поддержку РСЯ.

9. Изменения политики

При изменении практики обработки данных мы обновим эту страницу и дату «Последнее обновление». Существенные изменения будут отмечены в описании обновления приложения.

Privacy Policy

Last updated: 21 September 2026

In short. AdPocket is an independent app for viewing Yandex Advertising Network (YAN) statistics. It has no server of its own. Your OAuth token and all statistics stay on your device and are sent only to Yandex's API. The app contains no ads, analytics or trackers and sends nothing to the developer or any third party.

AdPocket is not an official Yandex application. Yandex, Yandex Advertising Network and related trademarks belong to Yandex LLC.

1. Who processes the data

The app developer ("we") is an individual; contact details are in section 10. The app runs entirely on your device; we do not receive, see or store your data.

2. What data the app uses and where it is stored

Statistics API OAuth token (one per account you add)Requesting statistics from Yandex's API on your behalfOn the device only: Android Keystore / iOS Keychain. On iOS the token is also readable by the app's widget through a shared Keychain access group.

The app does not collect or store your name, e‑mail, phone number, location, contacts, advertising identifiers, usage data or crash reports. There are no accounts on our side.

3. Who receives data

The only recipients of network requests are Yandex servers: partner2.yandex.ru and partner.yandex.ru (Yandex Advertising Network API). Each request carries your OAuth token in the Authorization header plus report parameters (period, metrics, filters, language, currency). Yandex's handling of that data is governed by its own documents: the Partner Interface API User Agreement and the Yandex Privacy Policy.

We share data with no one else. The app contains no analytics SDKs, advertising SDKs, crash reporters or push servers.

4. Permissions and device features

  • Internet — requests to Yandex's API.
  • Biometrics / device credential (Android USE_BIOMETRIC, iOS Face ID / Touch ID) — only if you enable "App lock". Biometric data is handled by the operating system and never reaches the app.
  • Home-screen widget — shows cached statistics; on Android, with "Background refresh" on, the app asks Yandex's API for statistics about every 30 minutes; on iOS the widget refreshes itself on the system's schedule.
  • Battery optimisation (Android) — with your consent the app opens the system battery-optimisation list so you can exclude AdPocket and keep the widget's background refresh running. No special permission is requested for this.
  • Notifications — local, generated on the device on your schedule; no push servers are used.

5. Retention and deletion

Data stays on the device for as long as you use the app. Remove an account and its token via Settings → Accounts → Remove account; clear cached reports via "Clear report cache". Uninstalling the app deletes all its data. You can revoke the token on Yandex's side in the partner.yandex.ru interface.

6. Security

Tokens live in the operating system's secure store and all requests use HTTPS. We recommend enabling "App lock" if others use your device. We cannot recover tokens or data because we never have them.

7. Children

The app is intended for Yandex Advertising Network partners and is not directed at anyone under 18.

8. Your rights

Because the data exists only on your device, you control it fully: viewing, changing and deleting are available in the app. For questions about data processed by Yandex, contact YAN support.

9. Changes to this policy

If data practices change we will update this page and the "Last updated" date. Material changes will be noted in the app's release notes.
